# nga-figma-bridge/figma-plugin
ROLE: Figma plugin · "NGA Figma Bridge" dev plugin (dynamic-page, localhost-only network)
Main thread (code.js) runs commands one at a time with a protected-page guard; the UI iframe (ui.html) keeps the WebSocket to the hub and does browser work (HTML layout, fetch).

## files
assets/ → icon.svg (N with a truss-bridge diagonal), icon-512/128/32.png
code.js: GENERATED by build.ts (core.js + handlers) — do not edit
core.js: dispatcher, job queue, ctx helpers, page guard, batch/exec/ping, hot-reload loader, ERROR_CODES mirror
manifest.json: plugin id (Figma-assigned on publish), ui, allowedDomains localhost:7777 (http + ws)
ui.html: dark ambient UI (centered connect button; canvas: glow-dot lattice (random per-dot twinkle × drifting regional opacity field) + flowing waves, quiet zone behind text; energy = connection state, busy = brighter flicker + wave glow/turbulence), WebSocket client, UI tasks (layout iframe runner, fetch, eval)
